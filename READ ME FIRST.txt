DATA TRAIN FOR WINDOWS

START HERE.html is the illustrated beginner's guide. Double-click it to open it
in your browser. It works without an internet connection.

QUICK START
1. Right-click the Data Train ZIP, choose Extract All, then Extract.
2. Open the extracted Data Train folder. Double-click Data Train.exe.
3. Download a data file from the Railroad Commission of Texas:
   https://www.rrc.texas.gov/resource-center/research/data-sets-available-for-download/
4. Drop that file into Data Train or click Choose a file. The RRC file can stay
   zipped. Check the detected dataset, then click Convert file.
5. Click Download results when the conversion is complete. Find the results
   ZIP in your browser's Downloads and extract it to open your files.
6. Click Quit app when you are finished.

Keep this whole folder together, including _internal. Do not run the program
from inside the Data Train ZIP or copy Data Train.exe out by itself. Python and
Node are included; you do not need to install them.
The Source Code folder is included for anyone who wants to inspect or modify
the program. You do not need it to run Data Train.

If the app does not start, extract the complete Data Train ZIP again. Closing
the browser tab alone leaves the app running; double-click Data Train.exe to
reopen it. Large downloads need time and free disk space.

CSV files can be opened in a spreadsheet. Import identifier columns as text to
keep leading zeros. Data Train also keeps results on your computer under:
  %LOCALAPPDATA%\Texas RRC Data Converter\Results

Images and PDFs are organized as files, without OCR. Oracle export dumps need
to be imported and exported as text first. GIS shapefiles are not converted.
The Windows build is unsigned. Large-file capacity and every field in every
dataset have not been fully verified; check important results against the source.
In Production Report for Pending Leases, a value beginning with a quotation
mark may lose that mark. The tested download had no such values.
