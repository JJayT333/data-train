DATA TRAIN 1.0.0
Local Texas Railroad Commission data converter for Windows x64

START IN THREE STEPS
1. Download Data-Train-1.0.0-Windows-x64.zip from:
   https://github.com/JJayT333/data-train/releases/latest
2. Right-click the ZIP and choose Extract All. Keep the entire folder together.
3. Open the extracted folder and double-click Data Train.exe.

Your browser opens the local app. Python, Node and libraries are included.
No developer tools, sign-in or runtime download is required.

CONVERT A FILE
Choose or drop an original RRC download. Confirm the recognized dataset, or
choose it if ambiguous. Click Convert file, then Download results. The results
ZIP contains CSV tables and a SQLite database. Use Quit app when finished.
Closing the browser tab alone leaves the app running; double-click Data Train.exe
to reopen it. Files are processed locally, not uploaded to an external service.

Supplied RRC headings are retained. Headerless formats use bundled RRC
manual-derived field names. CSV text values, including leading zeros, are kept.

IF THE APP WILL NOT START
Extract the complete ZIP again. Keep _internal beside Data Train.exe.
Do not run inside the ZIP or copy only the executable. Quit an earlier converter
build before starting Data Train.

Download actual data links from RRC, not a saved webpage. If recognition is
uncertain, choose the dataset named on RRC's download page. Nonempty CSV fields
beyond the headings cause a filename/line error instead of silently dropping
records. Empty trailing excess fields are accepted.

LIMITS
Images/PDFs are organized/indexed only, with no OCR or text extraction.
Pending-permit parsing is not yet verified. Shapefile/GIS conversion is outside
this release. Oracle dumps need Oracle import and text export first.
Large-file capacity and every field of every dataset are not fully verified.
This unsigned Windows x64 build has no tested first-download reputation/signing
or fresh Windows VM result. Keep normal Windows security protections enabled.
Mac is deferred; no Mac release or compatibility claim is made.

RESULTS AND LOGS
  %LOCALAPPDATA%\Texas RRC Data Converter
This internal storage name is kept for compatibility with earlier local builds;
the app is Data Train. Results remain after quit; downloads are separate copies.
The app chooses another local port if 5055 is occupied.
